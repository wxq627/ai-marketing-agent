# Strategy Agent 项目B任务日志

## 当前定位

项目B负责“策略编排与推荐大脑”，承接项目一 Knowledge Agent 的客户画像、意图、事件流、产品规则、权限规则和合规知识，输出项目三 Marketing Agent 可以执行的标准营销策略包，并接收项目三反馈完成复盘优化。

## 阶段任务拆解

### 阶段 1：接口合同对齐

状态：进行中

目标：

- 明确 A -> B 输入字段。

### 阶段 2：群像刻画与客群圈选

状态：待开始

目标：

- 从客户画像中抽取群体特征。
- 输出客群规模、典型标签、推荐理由、预估转化率和 ROI。
- 支持排除未授权、高投诉风险、触达过频客户。

### 阶段 3：策略生成与可解释

状态：待开始

目标：

- 输出渠道路由、预算分配、权益规则、内容大纲、合规边界和 A/B 实验方案。
- 每条策略都能解释“为什么这么推荐”。

### 阶段 4：联动项目三

状态：待开始

目标：

- 下发 C 端可执行策略包。
- 给单个客户提供推荐策略。
- 支持 C 端异常触发重新规划。

### 阶段 5：反馈复盘

状态：待开始

目标：

- 接收曝光、点击、转化、拒绝、投诉、ROI 等反馈。
- 输出客群、渠道、文案和预算的优化建议。
